🚀 Codeforces Accepted | A. Cubes Sorting 🧊💻

This problem looks like it requires simulating swaps or checking whether the array can be sorted step by step. However, the key observation makes the solution surprisingly simple.

🔗Problem Link: https://lnkd.in/gaqN6YtH

💡 Problem Insight
We need to determine whether the cubes can be sorted in non-decreasing order.
There are only two situations:
✅ Case 1: Duplicate Elements Exist
If the array contains at least one duplicate value, the answer is always:
YES

Because equal elements can be swapped without changing the array's order, allowing us to achieve the required arrangement.
✅ Case 2: All Elements Are Distinct
If every element is unique, then:
If the array is strictly decreasing, it cannot be sorted under the given operation.
Otherwise, the answer is:
YES

So, we only need to check whether the array is strictly decreasing.

⚡ Approach
Read the array.
Check if duplicate elements exist.
If yes, print YES.
Otherwise, determine whether the array is strictly decreasing.
If it is strictly decreasing, print NO.
Otherwise, print YES.
Instead of simulating swaps, we rely on two simple observations:
Duplicate values always make sorting possible.
Without duplicates, only a strictly decreasing sequence fails.

🔍 Code Explanation

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    if len(set(a)) < n:
        print("YES")
        continue

    decreasing = True
    for i in range(1, n):
        if a[i - 1] < a[i]:
            decreasing = False
            break

    print("NO" if decreasing else "YES")

✅ Read Input

t = int(input())

Read the number of test cases.
✅ Check for Duplicate Elements

if len(set(a)) < n:
    print("YES")
    continue

set(a) removes duplicate values.
If its size is smaller than n, duplicates exist.
In that case, the answer is immediately YES.
✅ Check Whether the Array Is Strictly Decreasing

decreasing = True

for i in range(1, n):
    if a[i - 1] < a[i]:
        decreasing = False
        break

Initially, assume the array is strictly decreasing.
If we find any adjacent pair where:

a[i-1] < a[i]

the array is not strictly decreasing, so sorting is possible.
✅ Print the Answer

print("NO" if decreasing else "YES")

If the array is strictly decreasing → NO
Otherwise → YES

⏱️ Time Complexity
Time Complexity: O(n) per test case
Creating the set → O(n)
Checking the array → O(n)
Overall → O(n)
Space Complexity: O(n)Due to storing elements in the set for duplicate detection.

🎯 Key Learning
Many sorting problems don't require actually sorting the array. By identifying special properties—in this case, duplicate elements and strictly decreasing order—we can replace simulation with a simple linear-time check.
